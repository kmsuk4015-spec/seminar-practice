# API 명세 요약: 행정안전부_법정동별(행정동 통반단위) 주민등록 인구 및 세대현황

> 공공데이터포털 상세 페이지의 "활용명세"를 옮겨 적은 것입니다(2026-10-17 확인).
> 이 페이지의 요청 주소와 요청 변수는 브라우저 화면에서만 그려져서, AI에게 주소만 주면 읽지 못하는 경우가 있습니다. 그래서 이 파일을 함께 줍니다.

- 상세 페이지: https://www.data.go.kr/data/15108071/openapi.do
- 제공기관: 행정안전부 / 이용허락범위: 제한 없음 / 심의: 개발·운영 자동승인 / 개발계정 하루 10,000건
- 데이터: 매월 말일 기준 주민등록 인구(거주자·거주불명자·재외국민 포함). 2022년 10월부터 조회 가능

## 요청 주소
```
https://apis.data.go.kr/1741000/stdgPpltnHhStus/selectStdgPpltnHhStus
```
