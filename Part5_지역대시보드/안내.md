# Part 5 실습 안내: 공공데이터로 우리 지역 현황 대시보드

오늘 만드는 것은 두 개입니다.
- **데이터받기.py**: 공공데이터포털 API에서 대구 9개 구·군의 인구·세대수를 받아 저장하는 프로그램(받는 쪽)
- **대시보드.html**: 받은 데이터를 차트와 표로 보여 주는 화면(보여 주는 쪽). 인증키가 들어가지 않음

## 폴더 안내

| 폴더·파일 | 내용 |
|---|---|
| `API_명세_요약.md` | 요청 주소, 요청 변수, 응답 항목, 오류 코드. AI에게 이 파일을 주고 프로그램을 요청합니다 |
| `미리받은데이터/` | 강사가 미리 받아 둔 응답(2026년 6~7월, 실제 값). 키가 없을 때 프로그램이 이 파일을 씁니다 |
| `갱신시험용/` | 한 달 뒤 다시 받은 것처럼 8월까지 든 응답. "다시 받으면 갱신되는지" 확인할 때 씁니다 |
| `원자료/` | 같은 값의 원본 CSV(대구광역시 제공). 숫자 3개를 대조할 때 엑셀로 엽니다 |
| `.env.example` | 인증키를 넣는 파일의 견본 |

## 내 경로 고르기

| | 인증키가 **없는** 사람(기본) | 인증키가 **있는** 사람 |
|---|---|---|
| 준비 | 없음 | `.env.example`을 복사해 `.env`로 저장하고 일반 인증키를 붙여 넣기. 포털에서 이 API를 활용신청해 두었는지 확인 |
| 데이터받기.py 실행 | 키가 없으니 `미리받은데이터`의 파일을 읽어 처리 | API를 직접 불러 받은 응답을 저장하고 처리 |
| 다시 받기 확인 | `갱신시험용`의 파일을 `미리받은데이터`로 복사한 뒤 다시 실행 | 조회 기간을 바꿔 다시 실행 |

두 경로 모두 대시보드는 똑같이 만들어집니다. 키가 없어도 실습 내용은 같습니다.

## 지킬 것
- 인증키는 `.env`에만 둡니다. 대화창, 프로그램 코드, 대시보드, 캡처, 메신저에 넣지 않습니다.
- Claude가 키를 물어보면 알려 주지 말고 "키는 .env에 있어. 너는 열지 마."라고 답합니다.
- 오류 메시지를 AI에게 붙여 넣기 전에 키가 섞여 있지 않은지 확인합니다(주소에 `serviceKey=`가 보이면 그 부분을 지우고 붙여 넣기).
- 숫자는 AI가 옮겨 적지 않습니다. 프로그램이 계산하고, 사람은 원자료와 대조합니다.
