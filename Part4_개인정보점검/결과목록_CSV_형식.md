# 결과목록 CSV 형식 (채점기와의 약속)

점검 앱이 내보내는 결과목록은 아래 형식을 **그대로** 따릅니다. 강사의 채점기가 이 형식만 읽습니다.
열 이름이나 순서가 바뀌면 채점이 되지 않습니다. 앱을 고칠 때도 이 형식은 바꾸지 않습니다.

## 파일
- 파일 이름: `결과목록_날짜-시각.csv` (예: `결과목록_20261020-1450.csv`)
- 글자 저장 방식: UTF-8(BOM 포함). 엑셀에서 열어도 한글이 깨지지 않게
- 구분: 쉼표. 값 안에 쉼표가 있으면 큰따옴표로 감쌈
- 한 줄 = 찾은 항목 하나

## 열 (첫 줄은 정확히 이 다섯 단어)

```
파일명,위치,유형,가린값,확실도
```

| 열 | 쓰는 법 | 예 |
|---|---|---|
| 파일명 | 점검한 파일 이름 그대로(확장자 포함) | `01_생활지원금_신청자명단.xlsx` |
| 위치 | 엑셀: `시트이름!칸주소`, 메모는 뒤에 `(메모)`, 칸 주소가 없는 곳은 괄호로(`시트이름!(머리글·바닥글)`, `시트이름!C5(링크)`). 한글: `본문`, `표`, `미리보기`, `문서정보` 중 하나(뒤에 설명을 붙여도 됨). CSV: 칸 주소(`B3`) | `명단!E7`, `명단!B6(메모)`, `표 2행`, `B3` |
| 유형 | 아래 9가지 이름 중 하나. 그 밖의 것은 자유롭게(예: 성명) | `휴대전화` |
| 가린값 | 원래 값은 절대 쓰지 않음. 아래 규칙대로 일부만 보이게 | `010-****-5678` |
| 확실도 | `확실` 또는 `의심` | `의심` |

## 유형 이름 9가지
주민등록번호, 외국인등록번호, 여권번호, 운전면허번호, 휴대전화, 일반전화, 이메일, 계좌번호, 주소

## 가린값 규칙 (보이게 둘 부분)

| 유형 | 보이게 둘 부분 | 예 |
|---|---|---|
| 주민등록번호·외국인등록번호 | 앞 7자리 | `900101-1******` |
| 휴대전화·일반전화 | 앞 번호와 끝 4자리 | `010-****-5678`, `053-***-1234` |
| 이메일 | 아이디 앞 2글자와 @ 뒤 전체 | `ab***@example.com` |
| 주소 | 도로명(○○로·○○길)까지 | `대구광역시 중구 ○○로 ***` |
| 계좌번호 | 끝 4자리 | `***-****-5678` |
| 여권번호 | 앞 4자리 | `M123*****` |
| 운전면허번호 | 앞 5자리와 끝 2자리 | `11-23-******-01` |

> 전부 `*`로 가리면 채점기가 어느 항목인지 알 수 없어 "채점 불가"로 셉니다.
> 이 형식은 강사가 정한 실습용 약속입니다. 실제 기관에서는 소속 기관의 표시 제한(마스킹) 기준을 따릅니다.
